# MBVD-Fitting
**Introduce**: \
This project, conducted during my time at Tsinghua University, involved the estimation of MBVD (Modified Butterworth-Van Dyke) model parameters for FBAR (Film Bulk Acoustic Resonator) resonators. The impedance data was measured using a Vector Network Analyzer (VNA), and from this data, I estimated the following MBVD parameters: R0, C0, R1, L1, C1, Rs. \
\
